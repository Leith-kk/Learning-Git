# Linux Vim 编辑器使用指南

> 参考来源：[菜鸟教程 - Linux vi/vim](https://www.runoob.com/linux/linux-vim.html)

---

## 一、什么是 Vim？

**Vim** 是从 **vi** 发展出来的一个文本编辑器。所有的 Unix Like 系统都会内建 vi 文书编辑器。

Vim 具有程序编辑的能力，可以主动地以字体颜色辨别语法的正确性，方便程序设计。它的功能非常丰富，包括代码补全、编译及错误跳转等，在程序员中被广泛使用。

简单来说，vi 是老式的字处理器，功能已经很齐全；而 vim 则是程序开发者的一项很好用的工具。连 vim 的官方网站（https://www.vim.org/）也自称 vim 是一个**程序开发工具**而不是文字处理软件。

## 二、Vim 的三种模式

Vim 共分为三种模式：

| 模式 | 英文名称 | 说明 |
|------|----------|------|
| **命令模式** | Command Mode / Normal Mode | 用户刚启动 vim 时进入此模式，敲击键盘被识别为命令而非输入字符 |
| **输入模式** | Insert Mode | 按下 `i` 等键后进入，可以编辑文本 |
| **底线命令模式** | Command-Line Mode | 按下 `:` 后进入，可输入保存、退出等命令 |

**模式切换流程：**

```
命令模式  ──→ 输入模式    (按 i, a, o 等键)
输入模式  ──→ 命令模式    (按 Esc 键)
命令模式  ──→ 底线命令模式 (按 : 键)
底线命令模式 ──→ 命令模式  (按 Esc 键)
```

## 三、命令模式下的常用命令

命令模式是 Vim 的默认模式，也是操作效率最高的模式。以下按**使用频率从高到低**排列。

### 3.1 光标移动（最常用）

| 命令 | 说明 | 频率 |
|------|------|------|
| `h` / `←` | 光标向左移动一个字符 | ★★★★★ |
| `j` / `↓` | 光标向下移动一个字符 | ★★★★★ |
| `k` / `↑` | 光标向上移动一个字符 | ★★★★★ |
| `l` / `→` | 光标向右移动一个字符 | ★★★★★ |
| `0` / `Home` | 移动到行首 | ★★★★★ |
| `$` / `End` | 移动到行尾 | ★★★★★ |
| `gg` | 移动到文件第一行 | ★★★★☆ |
| `G` | 移动到文件最后一行 | ★★★★☆ |
| `nG` | 移动到第 n 行（如 `20G` 跳转到第 20 行） | ★★★★☆ |
| `Ctrl + f` / `Page Down` | 向下翻一页 | ★★★★☆ |
| `Ctrl + b` / `Page Up` | 向上翻一页 | ★★★★☆ |
| `w` | 跳到下一个单词开头 | ★★★☆☆ |
| `b` | 跳到上一个单词开头 | ★★★☆☆ |
| `e` | 跳到当前单词词尾 | ★★★☆☆ |
| `n<Space>` | 光标向右移动 n 个字符（如 `20<Space>`） | ★★★☆☆ |
| `n<Enter>` | 光标向下移动 n 行 | ★★★☆☆ |
| `H` | 移动到屏幕最上方那行 | ★★☆☆☆ |
| `M` | 移动到屏幕中央那行 | ★★☆☆☆ |
| `L` | 移动到屏幕最下方那行 | ★★☆☆☆ |
| `Ctrl + d` | 向下移动半页 | ★★☆☆☆ |
| `Ctrl + u` | 向上移动半页 | ★★☆☆☆ |
| `+` | 光标移动到非空格符的下一行 | ★★☆☆☆ |
| `-` | 光标移动到非空格符的上一行 | ★★☆☆☆ |

### 3.2 搜索与替换

| 命令 | 说明 | 频率 |
|------|------|------|
| `/word` | 向光标**下方**搜索名为 `word` 的字符串 | ★★★★★ |
| `n` | 重复上一次搜索方向（继续向下搜索） | ★★★★★ |
| `N` | 反向重复上一次搜索（向上搜索） | ★★★★☆ |
| `?word` | 向光标**上方**搜索名为 `word` 的字符串 | ★★★☆☆ |
| `:%s/old/new/g` | 全文替换，将所有 `old` 替换为 `new` | ★★★★☆ |
| `:%s/old/new/gc` | 全文替换，每次替换前询问确认 | ★★★★☆ |
| `:n1,n2s/old/new/g` | 在第 n1 到 n2 行之间替换 | ★★★☆☆ |
| `*` | 向后搜索光标所在的单词 | ★★★☆☆ |
| `#` | 向前搜索光标所在的单词 | ★★★☆☆ |
| `%` | 跳转到匹配的括号 `( )` `{ }` `[ ]` | ★★☆☆☆ |

### 3.3 删除

| 命令 | 说明 | 频率 |
|------|------|------|
| `x` | 删除光标所在处的一个字符（向后删，相当于 Del） | ★★★★★ |
| `dd` | **剪切（删除）当前行** | ★★★★★ |
| `ndd` | 向下剪切 n 行（如 `10dd` 删除 10 行） | ★★★★☆ |
| `X` | 向前删除一个字符（相当于 Backspace） | ★★★★☆ |
| `nx` | 连续向后删除 n 个字符（如 `10x`） | ★★★☆☆ |
| `d$` | 删除光标所在处到行尾 | ★★★☆☆ |
| `d0` | 删除光标所在处到行首 | ★★★☆☆ |
| `d1G` | 删除光标所在处到第一行 | ★★☆☆☆ |
| `dG` | 删除光标所在处到最后一行 | ★★☆☆☆ |

### 3.4 复制与粘贴

| 命令 | 说明 | 频率 |
|------|------|------|
| `yy` | **复制当前行** | ★★★★★ |
| `nyy` | 复制向下 n 行（如 `20yy` 复制 20 行） | ★★★★☆ |
| `p`（小写） | 将已复制的数据**粘贴到光标下一行** | ★★★★★ |
| `P`（大写） | 将已复制的数据**粘贴到光标上一行** | ★★★★☆ |
| `y1G` | 复制光标所在行到第一行的所有数据 | ★★☆☆☆ |
| `yG` | 复制光标所在行到最后一行的所有数据 | ★★☆☆☆ |
| `y0` | 复制光标所在字符到该行行首的数据 | ★★☆☆☆ |
| `y$` | 复制光标所在字符到该行行尾的数据 | ★★☆☆☆ |

### 3.5 撤销与重做

| 命令 | 说明 | 频率 |
|------|------|------|
| `u` | **撤销**上一次操作（Undo） | ★★★★★ |
| `Ctrl + r` | **重做**上一次撤销的操作（Redo） | ★★★★☆ |
| `.` | **重复**前一个动作（非常实用的快捷键） | ★★★★☆ |

### 3.6 其他常用命令

| 命令 | 说明 | 频率 |
|------|------|------|
| `J` | 将当前行与下一行合并为同一行 | ★★★☆☆ |
| `r` | 替换光标所在的一个字符 | ★★★☆☆ |
| `R` | 进入替换模式，持续替换字符直到按 Esc | ★★★☆☆ |
| `>>` | 增加缩进 | ★★★☆☆ |
| `<<` | 减少缩进 | ★★★☆☆ |
| `ZZ` | 保存当前文件并退出（等同于 `:wq`） | ★★★★☆ |
| `ZQ` | 不保存强制退出（等同于 `:q!`） | ★★☆☆☆ |

## 四、输入模式下的操作

从命令模式按以下键进入输入模式：

| 命令 | 说明 | 频率 |
|------|------|------|
| `i` | **从光标当前位置开始输入** | ★★★★★ |
| `I` | 从当前行的第一个非空格符处开始输入 | ★★★☆☆ |
| `a` | **从光标下一个位置开始输入**（追加） | ★★★★☆ |
| `A` | 从当前行的最后一个字符处开始输入 | ★★★☆☆ |
| `o` | **在光标下方插入新行**并进入输入模式 | ★★★★☆ |
| `O` | 在光标上方插入新行并进入输入模式 | ★★★☆☆ |
| `r` | 替换光标所在的一个字符（不进入输入模式） | ★★★☆☆ |
| `R` | 进入替换模式，持续替换字符直到按 Esc | ★★★☆☆ |
| `s` | 删除光标所在字符并进入输入模式 | ★★☆☆☆ |
| `S` | 删除当前行并进入输入模式 | ★★☆☆☆ |

在输入模式下可用的按键：

| 按键 | 功能 |
|------|------|
| 字符键 + Shift | 输入字符 |
| Enter | 换行 |
| Backspace | 删除光标前一个字符 |
| Del | 删除光标后一个字符 |
| 方向键（↑↓←→） | 在文本中移动光标 |
| Home / End | 移动光标到行首/行尾 |
| Page Up / Page Down | 上/下翻页 |
| Insert | 切换光标为输入/替换模式 |
| **Esc** | **退出输入模式，回到命令模式** |

> ⚠️ **提醒：在输入模式下，左下角会出现 `-- INSERT --` 或 `-- REPLACE --` 字样，此时才能输入字符。**

## 五、底线命令模式下的常用命令

在命令模式下按 `:`（英文冒号）进入底线命令模式。以下是**按使用频率从高到低**排列的命令：

### 5.1 保存与退出（最常用）

| 命令 | 说明 | 频率 |
|------|------|------|
| `:w` | **保存文件** | ★★★★★ |
| `:q` | **退出 Vim**（未修改时使用） | ★★★★★ |
| `:wq` | **保存并退出** | ★★★★★ |
| `:q!` | **强制退出，不保存修改** | ★★★★★ |
| `:w!` | 强制写入（文件为只读时使用） | ★★★☆☆ |
| `:wq!` | 强制保存并退出 | ★★★☆☆ |
| `:w [filename]` | 另存为新文件 | ★★★☆☆ |

### 5.2 文件操作

| 命令 | 说明 | 频率 |
|------|------|------|
| `:e [filename]` | 打开另一个文件进行编辑 | ★★★☆☆ |
| `:r [filename]` | 读入另一个文件的内容，插入到光标所在行后面 | ★★☆☆☆ |
| `:n1,n2 w [filename]` | 将第 n1 到 n2 行的内容保存为新文件 | ★★☆☆☆ |
| `:! command` | 暂时离开 vim 执行 shell 命令（如 `:! ls /home`） | ★★★☆☆ |

### 5.3 显示设置

| 命令 | 说明 | 频率 |
|------|------|------|
| `:set nu` | **显示行号** | ★★★★★ |
| `:set nonu` | 取消显示行号 | ★★★☆☆ |
| `:set hlsearch` | 高亮搜索匹配结果 | ★★★☆☆ |
| `:set nohlsearch` | 取消搜索高亮 | ★★★☆☆ |
| `:set paste` | 启用粘贴模式（避免粘贴时自动缩进） | ★★★☆☆ |
| `:set nopaste` | 关闭粘贴模式 | ★★★☆☆ |
| `:set ts=4` | 设置 Tab 宽度为 4 个空格 | ★★★☆☆ |
| `:syntax on` | 开启语法高亮 | ★★★☆☆ |
| `:syntax off` | 关闭语法高亮 | ★★☆☆☆ |

### 5.4 多窗口操作

| 命令 | 说明 | 频率 |
|------|------|------|
| `:sp [filename]` | 水平分割窗口 | ★★★☆☆ |
| `:vsp [filename]` | 垂直分割窗口 | ★★★☆☆ |
| `:q` | 关闭当前窗口 | ★★★☆☆ |
| `Ctrl + w + w` | 切换到下一个窗口 | ★★★☆☆ |

## 六、Vim 快速入门示例

### 创建并编辑一个新文件

```bash
$ vim runoob.txt
```

### 简单编辑流程

1. **启动 vim** → 进入命令模式
2. 按下 `i` → 进入输入模式，左下角出现 `-- INSERT --`
3. **编辑文本** → 输入内容
4. 按下 `Esc` → 回到命令模式（`-- INSERT --` 消失）
5. 输入 `:wq` → 保存并退出

### 常用编辑组合技巧

- **删除 50 行**：`50dd`
- **向下移动 20 行**：`20j`
- **复制 30 行**：`30yy`
- **全文搜索替换**：`:%s/old_text/new_text/g`
- **跳转到第 100 行**：先按 `100`，再按 `G`（或 `:100` + Enter）

---

> **总结：** Vim 的核心操作可以浓缩为三个步骤：
> 1. **命令模式**下移动光标、复制、删除、搜索
> 2. 按 `i` **进入输入模式**编辑文字
> 3. 按 `Esc` 回到命令模式，再按 `:` **进入底线命令模式**保存退出
>
> 熟练掌握 `h/j/k/l`、`i`、`Esc`、`:wq` 这四个操作，就能在 Vim 中完成基本的编辑工作了。
